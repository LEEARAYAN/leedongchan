03 · 시스템설계 7 / 13

구조 설계 방향성 설정

실시간 이상탐지 원인 모든 이상은 사람에게 의존하여 판단되고 있음 — 현 시스템은 센서만 존재하여 단순 데이터 나열만 가능 조치 방향 관리도 자동 판정을 통한 실시간 이상탐지 시스템 구축
AI 3계층 도입 원인 예측·감지·보정이 분리되어 있지 않아 단계별 권한 구분이 없음 조치 방향 예측, 감지, 보정을 통한 공정 최적화 설계 도입
암묵지 형식지화 원인 숙달된 소수의 개인 경험에 의존하여 작업하는 공정이 다수 식별됨 조치 방향 고장 모드 및 영향 분석(FMEA)을 통해 암묵지 항목들을 체계화
감시 단위 전환 원인 기존 방식(배정번호)은 데이터의 해상도 저하 등 한계가 뚜렷함 조치 방향 4분 단위 청크로 데이터 해상도 향상 및 감시 지연 최소화

한계 및 유의사항

구분내용
자율보정 범위설비 제어 파라미터 중 심각도≥9 2건(소입로·솔트조 존온도)은 사람 확인 병행
감지 시점4분 만에 이상을 잡아도 노 안에는 이미 2시간치 물량이 처리 중. 해당 물량은 배출부 전수검사로 선별, 보정 효과는 이후 투입분부터 적용
사전예측 수준로지스틱회귀·결정트리 기준선 모델 및 정상구간 비교데이터 확보 후 통계적 학습 진행 예정
데모 데이터 성격고정 데이터셋 기반 시뮬레이션, 실시간 라인 연동 아님

PROTOTYPE · 테스트용 예측모델 초안 — 위험도 기반 조정 권고 (XGBoost)

한계점은 여전히 감지 시점이다. 4분 만에 이상을 잡아도 그 사이 2시간치 물량은 이미 처리 중이다. XGBoost로 위험확률을 실시간 산출해 처리 전·후 물량을 구분하는 방식을 초안으로 검토했다 — 정식 채택 모델이 아니라 구현 가능성만 확인한 참고용 시제품이며, 기준선 모델 확정 후 성능을 비교할 예정이다.

확장 방향

감시 단위 전환 현재 4분 단위 청크 기반, 즉각 반영 불가 방향 원시 시계열(초당) 기반으로 세부화해 해상도 상승
적용 범위 현재 열처리 단일 라인에만 반영 방향 전체 공정군으로 확장해 공정 최적화율 상승
자율도 현재 숙련자 경험이 충분히 학습 안 돼 사람 판단 필요 방향 경험 항목 체계화로 단계적 전 공정 자율화, 시스템 권한 확장
관리 특성 현재 외부 특성 기반으로 설계 방향 내부 특성 기반으로 시스템 확장
